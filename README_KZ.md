# Кулис Онлайн — көп ойыншы жобасының бастапқы нұсқасы

Бұл бумада Express + Socket.IO сервері және мобильді браузерге бейімделген клиент бар. Сервер бөлмелерді, кезекті, карталардың бастапқы таратылуын және ойын әрекеттерін басқарады.

## Жергілікті іске қосу
1. Node.js 20 немесе жаңасын орнатыңыз.
2. Терминалда жоба папкасына кіріңіз.
3. `npm install`
4. `npm start`
5. Браузерде `http://localhost:3000` ашыңыз.
6. Тест үшін екінші браузер/инкогнито терезеден кіріңіз, бөлме ашып/кодпен қосылыңыз.

Телефоннан сол Wi-Fi арқылы сынау үшін компьютердің жергілікті IP адресін тауып, `http://КОМПЬЮТЕР_IP:3000` ашыңыз. Firewall рұқсат етуі керек.

## Интернетке жариялау
Node.js қолданбасын және WebSocket қолдайтын хостингке серверді deploy етіңіз. Қоғамдық HTTPS доменін орнатыңыз. `ALLOWED_ORIGIN` мәнін өз доменіңізге қойыңыз. Бұл бастапқы нұсқа бір процесс/бір инстансқа арналған; бірнеше серверге масштабтау үшін Socket.IO adapter және shared room state қажет.

## Android
Осы `public` клиентті Android WebView контейнеріне енгізуге немесе HTTPS сайтты Android WebView/Trusted Web Activity-гаар нээж болно. Интернеттэх сервер HTTPS ашиглана. Бүтээгдэхүүний APK/Play Store багц одоогоор гараагүй.

## Маңызды шектеулер — жариялар алдында міндетті жұмыс
- Қазіргі HTML прототипінің ережелері толық емес/қайшылықты. Сервер қозғалтқышы тек бастапқы scaffold: ставка айналымын толық жабу, ұтыс/жеңіліс шарттары, side-pot, бот және толық дуэль барысы production-ready емес.
- Қазіргі карталар топтамасы 4 масть × 7 ранг = 28 карта. 9 ойыншыға 3 картадан (27) және козырьге 1 картаға жетеді, бірақ карталардың дәл ережесі бекітілуі тиіс.
- Socket ID — уақытша тұлға. Disconnect-тен кейін нақты reconnect token/account жүйесі жоқ; бөлме орнын уақытша резервтеу ғана бар.
- Тұрақты сақтау, rate limiting, бөлме құпиялығы, анти-cheat аудиті, серверге тесттер, мониторинг жоқ.
- Ойын виртуалды фишкалармен. Нақты ақша, ақшаға айырбастау немесе төлем қоспаңыз.
- Ойынның 2–9 адам режимі интерфейске енгізілді, алайда ережені қолмен тексеріп, барлық ойын жағдайына автоматты тест жазу қажет.

## Оқиғалар
- `room:create` `{name}` → `{roomId, playerId, room}`
- `room:join` `{roomId, name}`
- `room:leave`
- `game:start` — тек бөлме иесі
- `game:action` `{type:"look"|"blind"|"call"|"raise"|"fold"|"reveal"|"play", amount?, cardIndex?}`
- Server broadcast: `room:update`, private `game:state` (әр ойыншыға жеке қол картасымен).

## Келесі кезең
1. Кулист ережесін нақтылау және engine-ге unit тесттер.
2. Әрекеттерді толық turn-state machine етіп қайта жазу.
3. Reconnect identity + private invite rooms + persistence.
4. TLS hosting, logging, abuse limits, deployment.
5. Android production wrapper, app icon, signing, accessibility және құрылғыларда сынау.
